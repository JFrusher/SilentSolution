## Motivation

Every engagement today is generated by code: `ThreatDirector._spawn` for endless waves, and the six campaign
patrols are dicts in `campaign.py` that tweak the director (`rules`, `waves`, `boost`, `storm`). Adding a new
situation (a lone tanker in a gale, a hunter-killer pair, a big convoy at dawn) means writing Python. A scenario
format is the foundation for every other content issue: [[39]], [[40]] and [[41]].

## Proposal

**Scenario files** (`scenarios/*.toml`, read with the stdlib `tomllib`; no new dependency):

```toml
name = "Tanker in a gale"
rules = "COMMANDER"          # difficulty preset, overridable field by field below
seed = 0                     # 0 = random
[ocean]
rain = 0.8
layer_depth = 70
[own]
depth = 60
speed_kt = 4
[[group]]                    # a convoy, an independent, a hunter group...
kind = "convoy"
bearing = 40                 # relative to own ship, deg
range_km = 8
course = 270
speed_kt = 9
merchants = ["tanker", "freighter", "freighter"]   # class names (ship-classes issue)
escorts = ["corvette"]
[[objective]]
type = "sink_grt"
grt = 10000
```

- A loader validates the file (unknown keys, bad class names and out-of-range values give a clear error), then
  builds the world through the same spawn helpers the director uses. Refactor `_spawn` into reusable
  `spawn_convoy`, `spawn_independent` and `spawn_sub`.
- The campaign patrols move into scenario files; `campaign.PATROLS` becomes a list of file names.
- **Quick Battle** title option (**[Q] QUICK BATTLE**): a CRT form for convoy size, escort count and type, subs,
  weather, layer depth and difficulty, which writes an in-memory scenario and sails. "Save as scenario" writes the
  TOML so players can share setups.
- Optional later: a `scenarios/` folder in the user's home for player-made files, listed on the Quick Battle page.

## Acceptance criteria

- [ ] The six campaign patrols load from scenario files and play the same as today (`campaign.py` self-check passes).
- [ ] Quick Battle can produce any combination the director can, plus fixed weather and layer.
- [ ] Malformed scenario files fail with a readable message, not a traceback.
- [ ] A test loads every bundled scenario and steps it for 60 s headless.

## Notes

Ship classes ([[31]]) supply the class names; until then `merchant` and `escort` are the only valid classes.
